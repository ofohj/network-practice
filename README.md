# Network Engineering Setup

Cisco Packet Tracer를 활용한 L2/L3 스위칭, 라우팅 및 보안 정책 구축 실습을 기록하는 공간입니다.

## 🌐 주요 실습 내용

* **L2/L3 Switching**: VLAN 분리, Inter-VLAN 라우팅, STP를 활용한 L2 루핑 방지 및 링크 가용성 확보
* **Routing & Security**: OSPF 동적 라우팅 최적화, Standard/Extended ACL 기반 트래픽 접근 제어 및 NAT/PAT 구성
* **Configuration Management**: 실습 토폴로지 구성안 및 Cisco CLI 설정 스크립트 관리

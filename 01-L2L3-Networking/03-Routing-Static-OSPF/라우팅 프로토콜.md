# 🌐 라우팅 프로토콜
- 데이터가 출발지에서 목적지까지 최적의 경로로 이동할 수 있도록 라우터 간 경로 정보를 교환하는 통신 규약
- 라우팅 프로토콜을 통해 라우터는 (1)네트워크의 경로 정보를 수집하고, (2)라우팅 테이블을 구성하여 (3)최적의 경로로 데이터 패킷을 전송할 수 있음

## 🪼 라우팅 프로토콜의 종류

<img width="1049" height="253" alt="image" src="https://github.com/user-attachments/assets/d9246d92-ce85-436d-bb80-8196dcecb24b" />

- **정적 라우팅:** 패킷 전송이 이루어지기 전에 경로 정보를 라우터가 미리 저장하여 중개하는 방식
- **동적 라우팅:** 라우터의 경로 정보가 네트워크 상황에 따라 동적으로 변경되어 중개하는 방식
  - **IGP:** AS(Autonomous System, 자치 시스템: 하나의 라우팅 정책을 공유하는 라우터 집합) 내에서만 소통
  - **EGP:** AS끼리 소통
  - **라우팅 알고리즘**
    - 거리 벡터 알고리즘: 인접 라우터와 정보를 공유하여 목적지까지의 거리와 방향을 결정
    - 링크 상태 알고리즘: 링크 상태 정보를 모든 라우터에 전달하여 **최단 경로**를 구성하는 알고리즘으로, 다익스트라 알고리즘 사용
      - 장점: 네트워크를 일관성있게 파악할 수 있으며, 트래픽을 광범위하게 전달할 수 있음
      - 단점: 거리 벡터 알고리즘에 비해 계산이 더 복잡함

## 🪼 동적 라우팅 상세

### 1. RIP(Routing Information Protocol)
- 벨만 포드 알고리즘을 사용함
- **인접 라우터와 주기적으로(30초) 정보를 교환**하여 라우팅 테이블을 갱신하고 구성, 계산함
- 최대 홉 수를 **15개**로 제한함
- UDP 520번 포트를 사용하여 통신

### 2. OSPF(Open Shortest Path First) 
**>>> 본 실습에서 사용하는 라우팅 프로토콜**
- 규모가 크고 복잡한 TCP/IP 네트워크에서 RIP의 단점을 개선하기 위해 만들어진 라우팅 프로토콜
- 자치 시스템을 area로 나누어 라우팅을 효과적으로 관리
- 다익스트라 알고리즘 사용
- 홉 카운트에 제한이 없음

### ☆ RIP vs OSPF 비교표

|  | RIP | OSPF |
| --- | --- | --- |
| AS 범위 | IGP (AS 내부) | IGP (AS 내부, Area 단위 계층적 관리) |
| 알고리즘 | 거리 벡터(벨만 포드 알고리즘) | 링크 상태(다익스트라 알고리즘) |
| 작동 방식 | 인접 라우터와 30초마다 브로드캐스팅으로 정보를 교환 | 변경 즉시 Flooding, 변경 없으면 30분마다 갱신 |
| 최대 홉 수 | 15홉 | 제한없음 |

### 3. BGP(Border Gateway Protocol)
- 변경 발생 시 **경로 벡터 알고리즘을 통해** 대상까지의 최단 거리를 선정하고, TCP 통신을 통해 AS로 라우팅 정보를 신뢰성 있게 전달
- 주로 ISP 사업자들끼리 사용
- 즉, 최단 거리 도출보다는 ISP 간의 계약, 비용, 보안 정책에 따라 경로를 결정(예: "속도는 조금 느려도 A 통신사망 대신 B 통신사망을 거쳐서 가라")
- 장점: 라우팅 프로토콜 중 유일하게 TCP(179번 포트)를 사용하여 이웃 관계를 맺고 안정적으로 경로 정보를 교환
- 단점: 라우팅 비용이 많이 들고, 라우팅 테이블의 크기가 커서 메모리 사용량이 많음

### ☆ RIP vs OSPF vs BGP 비교표

|  | RIP | OSPF | BGP |
| --- | --- | --- | --- |
| AS 범위 | IGP (AS 내부) | IGP (AS 내부, Area 단위 계층적 관리) | EGP (AS 간 통신) |
| 알고리즘 | 거리 벡터(벨만 포드 알고리즘) | 링크 상태(다익스트라 알고리즘) | 경로 벡터 알고리즘 |
| 작동 방식 | 인접 라우터와 30초마다 브로드캐스팅으로 정보를 교환 | 변경 즉시 Flooding, 변경 없으면 30분마다 갱신 | 변경이 발생할 때만 정보가 갱신되며, 통신 주체 사이의 계약에 따라 경로 결정 |
| 최대 홉 수 | 15홉 | 제한없음 | 제한없음 |

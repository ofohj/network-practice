    | 구분 | Cisco 2911 | Cisco 4331 |
    | --- | --- | --- |
    | **세대** | 2세대 ISR(구형 모델) | 4세대 ISR(현행 표준 모델) |

## 2. 스위치 & 라우터 기본 설정
### 1) 스위치 CLI
```bash
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name Admin
Switch(config-vlan)# vlan 20
Switch(config-vlan)# name User
Switch(config-vlan)# exit

Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

Switch(config)# interface fastEthernet 0/2
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20

Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport mode trunk
```

### 2) 라우터 CLI
```bash
Router> enable
Router# configure terminal
Router(config)# interface gigabitEthernet 0/0/0
Router(config-if)# no shutdown
Router(config-if)# exit

Router(config)# interface gigabitEthernet 0/0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0

Router(config)# interface gigabitEthernet 0/0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
```

**💡 궁금한 점**

> Q1. config-if와 config-subif의 차이?

```
A1.
config-if는 실제 눈에 보이는 물리 포트를 설정하는 모드이고,
config-subif는 하나의 물리포트를 논리적으로 쪼갠 가상 서브 인터페이스를 설정하는 모드이다.

config-if에 들어갈 때는 명령어 `interface gigabitEthernet 0/0`를 입력하고,
config-subif에 들어갈때는  `interface gigabitEthernet 0/0.10`을 입력한다.

물리포트는 1개여서 구분할 필요가 없지만 가상포트는 여러개이기 때문에 구분을 위해 .10 처럼 할당된 번호를 같이 붙여준다.
```

> Q2. encapsulation dot1Q 10의 의미

```
A2.
- encapsulation: 패킷을 내보낼 때 표준 규칙으로 포장한다는 뜻
- dot1Q: IEEE 802.1Q로, 전 세계 표준 VLAN 태깅 프로토콜의 이름(IEEE 802.1Q를 실무에선 dot1Q라고 읽는다고 함)
- 10: VLAN의 ID 번호
- 최종 의미: 이 서브 인터페이스는 VLAN 10번 태그가 달린 채 들어온 패킷을 처리하고, 나갈때도 VLAN 10 태그를 붙여 캡슐화해서 내보내라
```

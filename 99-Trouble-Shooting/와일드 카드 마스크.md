## OSPF 라우팅 설정 시 와일드 카드 마스크 계산 방법
라우터가 자기가 연결하고 있는 네트워크 대역들을 이웃 라우터에게 Advertise하도록 설정할 때, 네트워크의 IP 주소와 와일드 카드 마스크(IP 주소 검사 범위)를 설정해주어야 함

### ★ 알아야 할 개념: 서브넷 마스크 vs 와일드카드 마스크
  
  | 구분 | 서브넷 마스크 | 와일드카드 마스크 |
  | --- | --- | --- |
  | 역할 | IP 주소에서 네트워크/호스트 영역 구별 | IP 주소에서 검사할 범위 지정 |
  | 1비트의 의미 | 네트워크 영역 | 상관없음 |
  | 0비트의 의미 | 호스트 영역 | 일치해야 함 |
  | 표기 규칙 | 1이 먼저 나오고 뒤에 0이 옴 | 0이 먼저 나오고 뒤에 255가 옴 |

  ---
  
### ★ 와일드카드 마스크 계산 방법

▶️ **와일드카드 마스크 = 255.255.255.255 - 서브넷 마스크**

- **와일드 카드 마스크 계산법**
  
  **(1) 본사 LAN 서브넷 마스크 확인:** 255.255.255.0
  
  **(2) 255.255.255.255 - 서브넷마스크 =** 0.0.0.255
  
  **(3) 라우터 간 통신을 위한 WAN 서브넷 마스크 확인:** 255.255.255.252

  💡여기서 잠깐, 왜 255.255.255.**252**일까?
  - 라우터와 라우터 간 1:1 직렬 연결 시, 불필요한 IP 주소 낭비를 막기 위한 최적의 크기가 252임
  - 왜? >> 서브넷 마스크를 지정할 때, 11111111.11111111.11111111.111111(네트워크 영역: 30비트)00(호스트 영역: 2비트)가 되기 때문
  - 2비트로 만들 수 있는 IP 주소의 수
    - 10.10.10.0(네트워크 주소): 이 동네 전체를 대표하는 주소로, 장비 할당 불가
    - 10.10.10.1(할당된 IP 주소): Router0의 WAN 포트(0/0/1)에 부여
    - 10.10.10.2(할당된 IP 주소): Router1의 WAN 포트(0/0/1)에 부여
    - 10.10.10.3(브로드캐스트 주소): 동네 전체에 외칠 때 쓰는 주소로, 장비 할당 불가
  
    => 라우터 2대만 연결하기 딱 알맞다는 것을 확인 할 수 있음!!

  
  **(4) 255.255.255.255 - 서브넷마스크 =** 0.0.0.3

### ★ (최종) 라우터 CLI 창에 다음과 같은 OSPF 정보 입력

```bash
configure terminal

# OSPF 프로세스 ID 1번 시작
router ospf 1

# 본사 LAN 대역 광고 (와일드카드 마스크 0.0.0.255 사용)
# 해석: Router0에 연결된 IP 주소 중 앞 세 자리는 정확히 일치해야 하며, 마지막 자리는 0~255 중 어떤 수든 올 수 있음
network 192.168.10.0 0.0.0.255 area 0

# WAN 대역 광고 (와일드카드 마스크 0.0.0.3 사용)
network 10.10.10.0 0.0.0.3 area 0

exit
```
